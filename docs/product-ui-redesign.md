# 门训打卡产品与界面重构说明

## 产品目标

系统围绕“今天要做什么、完成打卡、看见成长”设计。普通成员只接触日常学习所需功能；组长和管理员进入独立管理工作台，避免管理表单干扰打卡体验。

## 角色与核心模块

### 普通成员

- 今日打卡：查看当天任务、打开学习内容、完成或撤销打卡。
- 成长数据：查看连续打卡、月度完成率、历史日历和小组进度。
- 学习资源：按读物、视频、讲义等分类查看组内资料。
- 个人中心：修改头像、展示用户名、邮箱、密码和默认小组。
- 小组切换：主修、辅修共用账号，在已加入的小组间切换。

### 组长与组管理员

- 管理概览：今日完成情况、成员规模、待处理事项和快捷入口。
- 任务计划：按周查看和编辑任务，常用内容优先，高级配置折叠。
- 成员权限：查看成员状态、授予或取消本组管理员权限。
- 学习资源：上传、预览和管理本组资料。
- 数据工具：导出打卡和成员数据，导入周计划或历史备份。

### 全站超级管理员

- 拥有所有组的管理能力。
- 报名名单：Excel 预览与同步、冲突处理、逐人维护名单席位。
- 管理全站组别、组长权限和历史迁移数据。

## 关键流程

### 注册与首次进入

名单姓名和小组匹配 → 填写联系邮箱和密码 → 系统认领主修/辅修席位 → 展示生成用户名 → 自动进入所选小组的今日打卡页。

### 每日打卡

进入今日打卡 → 查看任务进度 → 打开读经/视频/背经内容 → 点击完成 → 页面即时更新进度和完成反馈。

### 管理任务

进入管理概览 → 选择任务计划 → 从左侧选择周次 → 编辑日期和学习内容 → 必要时展开高级设置 → 保存并返回概览确认。

## UI/UX 规则

- 使用接近现代 iOS 的浅色背景、分层卡片、柔和阴影和大圆角。
- 桌面端使用完整侧栏；移动端使用底部导航，不再用单字菜单。
- 主要按钮和移动端点击区域不小于 44px。
- 表单提供清楚的字段名称与说明，危险操作使用二次确认。
- 常用设置直接展示，高级配置按需展开。
- 加载、空状态、成功、错误和无权限状态使用统一反馈。
- 头像、用户名和小组上下文在所有相关页面保持一致。
